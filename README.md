# Student Information System (SIS)

This is a small Tkinter-based Student Information System (SIS) desktop app written in Python.

Contents
- `collegeapp.py` — main application GUI and logic
- `users.json`, `student_data.json`, `session.json` — local data files (ignored by git)

Requirements
- Python 3.8+
- openpyxl

Install dependencies:

```powershell
pip install -r requirements.txt
```

Run the app:

```powershell
python "collegeapp.py"
```

Notes
- Sensitive local data files (user accounts, session data, student data) are intentionally not tracked in the repository by default. If you want to include sample data, create `sample_users.json` / `sample_student_data.json` and add them instead.
- The app requires `openpyxl` for Excel export. Tkinter is provided by the standard Python distribution for most platforms.
